# Video to optimized GIF

Инструмент преобразует видео в зацикленный GIF и подбирает минимальную степень
сжатия, при которой файл проходит заданный лимит.

По умолчанию используется пресет, подобранный для ролика Balloon Lift:

- 720x405 (16:9);
- 7 кадров в секунду;
- пять автоматически найденных сцен;
- отдельная палитра до 96 цветов для каждой сцены;
- плавное снижение мелкой детализации по краям кадра;
- `gifsicle -O3` и бинарный поиск минимального `--lossy`;
- лимит 2 000 000 байт с запасом 10 000 байт;
- бесконечное зацикливание.

## Быстрый запуск

Если исходник находится в `Documents\resolve\Timeline 1.mp4`, достаточно
запустить:

```powershell
.\optimize-gif.cmd
```

Результат появится рядом с видео под именем
`Timeline 1_optimized_under_2MB.gif`.

Для другого файла:

```powershell
.\optimize-gif.cmd `
  -Source "C:\video\input.mp4" `
  -Output "C:\video\output.gif"
```

Чтобы заменить уже существующий результат, добавьте `-Force`:

```powershell
.\optimize-gif.cmd -Source "C:\video\input.mp4" -Force
```

## Полезные настройки

Больше или меньше кадров:

```powershell
.\optimize-gif.cmd -Source "C:\video\input.mp4" -FrameRate 8
```

Другой размер и лимит:

```powershell
.\optimize-gif.cmd `
  -Source "C:\video\input.mp4" `
  -Width 960 -Height 540 `
  -MaxBytes 2000000
```

Если количество сцен отличается от пяти:

```powershell
.\optimize-gif.cmd -Source "C:\video\input.mp4" -SceneCount 3
```

Отключить снижение детализации по краям:

```powershell
.\optimize-gif.cmd -Source "C:\video\input.mp4" -DisableEdgeReduction
```

Сделать эффект по краям слабее можно уменьшением `EdgeBlurSigma`, например:

```powershell
.\optimize-gif.cmd -Source "C:\video\input.mp4" -EdgeBlurSigma 0.8
```

Оставить временные PNG и промежуточные GIF для диагностики:

```powershell
.\optimize-gif.cmd -Source "C:\video\input.mp4" -KeepWorkFiles
```

## Как устроен процесс

1. FFmpeg создаёт единый ряд кадров в требуемом разрешении и FPS.
2. При включённой обработке краёв центр остаётся резким, а размытие плавно
   нарастает к периферии. GIF не умеет использовать отдельную палитру внутри
   разных областей одного кадра, поэтому уменьшение детализации даёт похожую
   экономию без видимой границы качества.
3. Смена сцен оценивается на готовом ряду кадров. Выбираются самые сильные и
   достаточно удалённые друг от друга склейки.
4. Каждая сцена кодируется со своей глобальной палитрой и отдельно проходит
   lossless-оптимизацию `gifsicle -O3`.
5. Сцены объединяются в правильном порядке.
6. Бинарный поиск находит минимальное значение `--lossy`, которое укладывает
   итоговый GIF в лимит.
7. Скрипт проверяет размер, разрешение, число кадров и бесконечный цикл.

## Зависимости

При первом запуске автоматически скачиваются:

- FFmpeg 9.0.1 essentials build с gyan.dev;
- Gifsicle 1.93 из пакета `gifsicle-bin` 7.0.1.

Они сохраняются в `%LOCALAPPDATA%\BalloonLift\GifOptimizer` и повторно не
скачиваются. В папку мода бинарные файлы и временные кадры не попадают.
