description=
description=Balloon Lift adds a practical use for the balloons in Authentic Z. Balloons attached to a backpack reduce the effective weight of its contents.
description=
description=A regular balloon reduces the weight by roughly 1 unit. A bundle of three reduces it by roughly 3. This can be adjusted in Sandbox Options.
description=
description=[h1]Setup[/h1]
description=[list]
description=[*]Made and tested on Project Zomboid 42.24 (SP & MP)
description=[*][b]Other Build 42 versions are allowed but have not been tested. Use at your own risk.[/b]
description=[*]Turn on either [b]Authentic Z - Current[/b] or [b]AuthenticZBackpacks+[/b]
description=[*]Can be added to an existing save
description=[/list]
description=For multiplayer, install Balloon Lift on the server and every client.
description=
description=[h1]For mod authors[/h1]
description=[h2]Custom balloons[/h2]
description=Balloon Lift automatically supports custom balloons attached to one of the recognized Authentic Z balloon locations.
description=
description=Add these properties directly to your balloon’s item definition:
description=
description=[code]
description=AttachmentType = BalloonSlot,
description=BalloonFactor = 1.7,
description=[/code]
description=
description=BalloonFactor accepts decimal values and defaults to 1 when omitted. The final lift is BalloonFactor multiplied by the value selected in Sandbox Options.
description=
description=A BalloonFactor defined in the item script takes priority over Balloon Lift’s built-in value for that item type.
description=
description=[h2]Custom attachment locations[/h2]
description=If your backpack uses its own attachment location, add that location to Balloon Lift from a client or shared Lua file:
description=
description=[code]
description=Events.OnGameBoot.Add(function()
description=    local api = AuthenticZBalloonLift
description=    if not api or not api.BALLOON_LOCATIONS then return end
description=
description=    table.insert(
description=        api.BALLOON_LOCATIONS,
description=        "Your Balloon Location"
description=    )
description=end)
description=[/code]
description=
description=Use the exact attached-location ID defined by your backpack. This is the value passed to getOrCreateLocation(), not the item’s AttachmentType.
description=
description=For example, if your backpack defines:
description=
description=[code]
description=group:getOrCreateLocation("Your Balloon Location")
description=[/code]
description=
description=register the same "Your Balloon Location" string with Balloon Lift.
